# Buraco do Zé

> Este jogo é para lembrar os velhos tempos em que Dil e Anderson jogavam o buraco aberto.

Jogo de buraco aberto online para jogar com os amigos — 2 jogadores ou 4 em duplas.

Regras completas e planejamento em [PROJETO.md](PROJETO.md).

## Estrutura
- `engine/` — motor de regras (TypeScript puro, sem dependências)

## Rodando os testes
```bash
cd engine
npm install
npm test
```
